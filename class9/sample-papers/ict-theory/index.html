ICT Theory Sample Paper (30 Marks)

Syllabus: Part A Unit 1 Communication Skills, Part B Unit 3 Digital Documentation

Q1. Communication cycle ends with?
Answer: Feedback
Explanation: Feedback confirms message understanding.
Q2. Non-verbal communication example?
Answer: Eye contact
Explanation: Body language is non-verbal.
Q3. Save shortcut in Writer?
Answer: Ctrl+S
Explanation: Standard save command.
Q4. Define feedback.
Answer: Receiver's response to sender.
Explanation: It completes two-way communication.
Q5. Explain communication cycle.
Answer: Sender -> Idea -> Encoding -> Channel -> Receiver -> Decoding -> Feedback.
Explanation: Each step ensures proper transfer and response.
Q6. Character vs paragraph formatting.
Answer: Character formatting changes text style; paragraph formatting changes block layout (alignment, spacing).
Explanation: Scope differs: selected text vs full paragraph.
Q7. Ordered vs unordered list.
Answer: Ordered uses numbers; unordered uses bullets.
Explanation: Ordered list shows sequence.
Q8. Steps to insert table.
Answer: Insert -> Table -> Choose rows/columns -> OK.
Explanation: Basic writer workflow.
