Mathematics Sample Paper (40 Marks)

Chapters: Number System, Polynomials

Q1. Is 0 rational?
Answer: Yes
Explanation: 0 = 0/1.
Q2. Decimal form of 2/5?
Answer: Terminating
Explanation: Denominator has only factor 5.
Q3. Degree of 5x2-3x+1?
Answer: 2
Explanation: Highest power is 2.
Q4. Define polynomial.
Answer: Algebraic expression with non-negative integer powers of variable.
Explanation: No variable in denominator/radical.
Q5. Find zeroes of p(x)=(x-1)(x+2).
Answer: x=1, x=-2
Explanation: Set each factor zero.
Q6. Rational vs irrational (with examples).
Answer: Rational = p/q (3/4), irrational = non-terminating non-repeating (root2, pi).
Explanation: Decimal behavior helps identification.
