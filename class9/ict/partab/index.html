Part A – Unit 1: Communication Skills – I

1. Communication

Communication is the process of exchanging information, ideas, thoughts, or feelings between two or more people.

Importance of Communication

  • Builds relationships
  • Helps in sharing information
  • Improves teamwork
  • Reduces misunderstandings

2. Methods of Communication

Method Meaning Example
Verbal Using words Conversation, Phone Call
Non-Verbal Without words Gestures, Facial Expressions
Visual Using images and symbols Charts, Signs, Posters

Verbal Communication

Oral Communication

  • Face-to-face conversation
  • Telephone call
  • Meetings

Written Communication

  • Letters
  • Emails
  • Notices

3. Non-Verbal Communication

  • Facial Expressions
  • Eye Contact
  • Posture
  • Hand Gestures

Decoding Understanding the message

Part B – Unit 3: Digital Documentation

1. Digital Documentation

Digital Documentation means creating, editing, formatting, and storing documents electronically.

Examples

  • Letters
  • Reports
  • Projects
  • Notices

2. Word Processor

A Word Processor is software used to create and edit documents.

Examples:

  • LibreOffice Writer
  • Microsoft Word

3. Features of LibreOffice Writer

  • Create documents
  • Edit text
  • Spell Check
  • Insert Images
  • Create Tables
  • Save Documents
