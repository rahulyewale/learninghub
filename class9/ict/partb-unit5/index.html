1. What is a Digital Presentation?

A Digital Presentation is a collection of slides displayed on screen to communicate information visually. LibreOffice Impress is the free presentation software in the LibreOffice suite.

TermMeaning
SlideA single page in a presentation
Presentation / SlideshowA collection of slides shown in sequence
Slide LayoutPre-arranged positions for text/images on a slide
Slide TransitionAnimation effect when moving from one slide to the next
AnimationEffect applied to individual objects on a slide
Template / Master SlidePre-designed slide style applied to all slides
PlaceholderDotted box where title, content, or image goes
File format: LibreOffice Impress saves as .odp. It can also save as .pptx (PowerPoint format).

3. Creating and Managing Slides

Adding and deleting slides

  • Add slide: Right-click in slide panel → Insert Slide; or use Outline view → press Enter
  • Delete slide: Right-click slide thumbnail → Delete Slide
  • Duplicate slide: Right-click → Duplicate Slide
  • Reorder slides: Drag slide thumbnail in slide panel
  • Move slide: Cut (Ctrl+X) → click target position → Paste (Ctrl+V)

Adding content to slides

  • Click placeholder boxes to type text
  • Insert → Image to add pictures
  • Insert → Table to add a table
  • Insert → Chart to embed a chart
  • Insert → Media → Audio/Video to add media

Slide Layouts

Layouts define where content appears on a slide. Examples: Blank, Title Only, Title + Content, Two Content.

4. Design, Themes, and Master Slides

A Master Slide sets the background, font, colour scheme, and position of elements for all slides in a presentation.

  • View → Master → Slide Master to edit master slide
  • Apply pre-designed themes from the Properties panel (Master Pages)
  • Use consistent colours and fonts for professionalism

Design guidelines for good presentations

  • Keep text minimal — use bullet points, not paragraphs
  • Use font size 24 or larger for body text; 36+ for headings
  • Use high contrast between text and background
  • Limit one slide to one main idea
  • Use images and diagrams to illustrate points
  • Avoid overcrowding slides with too much content
Rule of thumb: Follow the 6×6 rule — no more than 6 bullet points per slide, no more than 6 words per bullet point.

5. Animations and Slide Transitions

Slide Transitions

Transitions are effects shown while moving from one slide to the next.

  • Select a slide → Slideshow → Slide Transitions
  • Choose type: Fade, Wipe, Dissolve, Push, etc.
  • Set speed and auto-advance time

Object Animations

Animations are effects applied to individual objects (text, image, shape) on a slide.

  • Select object → Slideshow → Animation
  • Add Effect: Entrance, Emphasis, Exit
  • Set trigger: On Click / After Previous / With Previous
  • Set duration and delay
Animation CategoryPurposeExample
EntranceObject appears on slideFly In, Fade In
EmphasisObject draws attention while on slideSpin, Pulse
ExitObject disappears from slideFly Out, Fade Out

6. Presentation Views

ViewPurpose
Normal ViewDefault editing view; shows single slide for design
Outline ViewShows all slide text in outline format; good for writing content
Slide Sorter ViewShows all slide thumbnails; easy to reorder slides
Notes ViewAdd speaker notes below the slide
Slideshow / Presentation ViewFull-screen display mode for the audience

Running the presentation

  • Press F5 to start slideshow from the beginning
  • Press Shift+F5 to start from the current slide
  • Press Esc to exit slideshow
  • Click mouse or press → (arrow key) to advance slides

7. Sample Questions with Answers

Q1. What is a slide transition? 1 Mark▼
Answer: A slide transition is the animation effect that appears when moving from one slide to the next during a presentation.
Q2. What is the file extension for LibreOffice Impress? 1 Mark▼
Answer: The file extension is .odp (OpenDocument Presentation). It can also be saved as .pptx.
Q3. What are the three types of animation effects in Impress? 2 Marks▼
Answer: (1) Entrance – object appears on the slide; (2) Emphasis – object draws attention while visible; (3) Exit – object leaves the slide.
Q4. Name and describe any four views available in LibreOffice Impress. 4 Marks▼
Answer: (1) Normal – editing single slide. (2) Outline – shows text outline of all slides. (3) Slide Sorter – shows all thumbnails for reordering. (4) Slideshow – full-screen presentation mode.
Q5. What is a Master Slide? How is it useful? 2 Marks▼
Answer: A Master Slide is a template that defines the background, colours, fonts and layout for all slides. It ensures a consistent look throughout the presentation.
Q6. List any four good design rules for creating presentations. 4 Marks▼
Answer: (1) Use bullet points, not paragraphs. (2) Keep font size 24+ for body. (3) Maintain contrast between text and background. (4) One main idea per slide. (5) Follow 6×6 rule.
Q7. How do you start a slideshow? How do you advance to the next slide? 2 Marks▼
Answer: Press F5 to start from beginning. Press Shift+F5 to start from current slide. Press the right arrow key or click mouse to advance slides. Press Esc to exit.
Quick revision: Impress = presentation; .odp format; Slide transition = between slides; Animation = on objects; Master Slide = common design; F5 = start slideshow; Views: Normal, Outline, Sorter, Notes, Slideshow.
