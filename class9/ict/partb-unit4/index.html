1. What is an Electronic Spreadsheet?

An Electronic Spreadsheet is a software application used to organise, calculate, and analyse data in rows and columns. LibreOffice Calc is the free, open-source spreadsheet included with the LibreOffice suite (default tool used in CBSE schools).

TermMeaning
WorkbookA Calc file that contains one or more sheets
Worksheet / SheetA single page of rows and columns within a workbook
CellThe intersection of a row and a column (e.g., A1, B3)
RowHorizontal arrangement of cells (numbered 1, 2, 3…)
ColumnVertical arrangement of cells (named A, B, C…)
Cell Address / ReferenceThe name of a cell, e.g., C5 means column C, row 5
Cell RangeA group of cells, e.g., A1:A10
Remember: File extension for LibreOffice Calc is .ods; it can also save as .xlsx (Excel format).

3. Entering and Editing Data

Types of Data

TypeMeaningAlignment in Cell
NumberNumeric values (123, 3.14)Right-aligned
Text / LabelWords, names, headingsLeft-aligned
Date / Time27/06/2026, 09:30 AMRight-aligned
FormulaStarts with = signShows result

Editing Cells

  • Click cell → type to enter data → press Enter to confirm
  • Press F2 or double-click cell to edit existing content
  • Press Delete to clear cell contents
  • Press Esc to cancel current entry
AutoFill: Select cells with a pattern and drag the fill handle (small square at corner) to extend the series automatically.

4. Formulas in Calc

A Formula always starts with the = sign and performs calculations using cell references, values, and operators.

Arithmetic Operators

OperatorOperationExample
+Addition=A1+B1
-Subtraction=A1-B1
*Multiplication=A1*B1
/Division=A1/B1
^Exponentiation (power)=A1^2

Cell References

TypeExampleMeaning
RelativeA1Changes when copied to another cell
Absolute$A$1Fixed – does not change when copied
Mixed$A1 or A$1One part fixed, one part changes
Tip: Press F4 to toggle between relative and absolute reference while typing a formula.

8. Sample Questions with Answers

Q1. What is a cell in a spreadsheet? 1 Mark▼
Answer: A cell is the intersection of a row and a column in a spreadsheet. It is identified by a cell address like A1 or C3.
Q2. How does a formula begin in Calc? Write a formula to add A1 and B1. 2 Marks▼
Answer: A formula in Calc always begins with the = (equals) sign. Formula to add A1 and B1: =A1+B1
Q3. Differentiate between relative and absolute cell reference. 2 Marks▼
Answer: Relative reference (e.g., A1) changes when copied to another cell. Absolute reference (e.g., $A$1) remains fixed and does not change when the formula is copied.
Q4. Write the syntax and purpose of IF, SUM, and AVERAGE functions. 3 Marks▼
Answer: SUM: =SUM(A1:A5) – adds all values; AVERAGE: =AVERAGE(A1:A5) – finds mean; IF: =IF(A1>50,"Pass","Fail") – returns value based on condition.
Q5. Name the file extension for LibreOffice Calc. What are the parts of the Calc interface? 3 Marks▼
Answer: File extension: .ods. Interface parts: Title Bar, Menu Bar, Toolbar, Name Box, Formula Bar, Column/Row headers, Sheet Tabs, Status Bar.
Q6. What are the different types of charts in Calc? When is a pie chart used? 3 Marks▼
Answer: Types: Bar, Column, Line, Pie, Area. Pie chart is used to show proportions or percentage shares of a whole.
Q7. How do you sort and filter data in LibreOffice Calc? 4 Marks▼
Answer: To Sort: select data → Data → Sort → choose column and ascending/descending order. To Filter: select data → Data → AutoFilter → click dropdown arrow on column header → select filter criteria.
Quick revision: Calc = spreadsheet; cell = row+column intersection; formula starts with =; SUM, AVERAGE, MAX, MIN, COUNT, IF are key functions; .ods file format; charts: Bar, Line, Pie.
