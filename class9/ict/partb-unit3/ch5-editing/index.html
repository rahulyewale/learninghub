1. Inserting and Deleting Text

Insert Mode vs Overtype Mode

Insert Mode (Default)Overtype Mode
New text is inserted at cursor position; existing text shifts rightNew text replaces (overwrites) existing text character by character
Default mode when Writer opensActivated by pressing the Insert key

Deleting Text

KeyAction
BackspaceDeletes character to the LEFT of the cursor
DeleteDeletes character to the RIGHT of the cursor
Ctrl+BackspaceDeletes one word to the left
Ctrl+DeleteDeletes one word to the right
Tip: Press Insert key to toggle between Insert and Overtype mode. The Status Bar shows OVR when Overtype is active.

2. Selecting Text

Selection is needed before performing operations like cut, copy, format or delete.

Mouse Selection

  • Click and drag — select any portion of text
  • Double-click — selects a word
  • Triple-click — selects an entire paragraph
  • Click in margin — selects a line; click+drag selects multiple lines

Keyboard Selection

KeysSelection
Shift + →/←Select one character at a time
Shift + ↑/↓Select one line at a time
Shift + HomeSelect from cursor to beginning of line
Shift + EndSelect from cursor to end of line
Ctrl + ASelect all text in the document
Ctrl + Shift + EndSelect from cursor to end of document
Ctrl + Shift + HomeSelect from cursor to beginning of document
Remember: Selected text appears highlighted (usually in blue). Any key pressed will replace the selection.

3. Cut, Copy and Paste

OperationShortcutDescription
CutCtrl+XRemoves selected text from its current location and places it in Clipboard
CopyCtrl+CCopies selected text to Clipboard — original text remains
PasteCtrl+VInserts the content from Clipboard at the cursor position
Paste SpecialCtrl+Shift+VPaste with options: unformatted text, formatted text, etc.

The Clipboard

The Clipboard is a temporary storage area in memory. It holds the last cut or copied content until something new is cut or copied, or the computer is restarted.

Drag and Drop

Another way to move text: Select text → hold the mouse button → drag to new position → release.

Move vs Copy: Cut + Paste = Move text | Copy + Paste = Duplicate text

4. Undo and Redo

ActionShortcutDescription
UndoCtrl+ZReverses the last action. Can be pressed multiple times to undo several actions.
RedoCtrl+YRepeats an action that was undone. Used after Undo to restore changes.
Remember: Writer keeps a history of actions. You can undo/redo multiple times using Ctrl+Z/Ctrl+Y or the toolbar arrows.

5. Find and Replace

Find locates a word or phrase in the document. Replace replaces a found word with a different word.

OperationShortcutPath
FindCtrl+FView → Find Bar or Edit → Find
Find and ReplaceCtrl+HEdit → Find & Replace

Steps to use Find and Replace

  1. Press Ctrl+H to open the Find & Replace dialog box
  2. In the Search For field, type the word to find
  3. In the Replace With field, type the replacement word
  4. Click Replace to replace one at a time, or Replace All to replace all occurrences
  5. Click Close when done
Exam tip: Find and Replace is very useful when a word appears many times and needs to be changed throughout the document.

6. Spelling and Grammar Check

LibreOffice Writer automatically checks spelling and grammar as you type.

How to use Spell Check

  • Right-click on underlined word → choose correct spelling from suggestions

7. AutoCorrect

AutoCorrect automatically corrects common typing mistakes as you type. For example: "teh" → "the", "dont" → "don't".

  • Access: Tools → AutoCorrect Options
  • You can add your own autocorrect entries
  • You can turn off AutoCorrect if it changes something you don't want

AutoText

AutoText lets you store and quickly insert frequently used text with a short code. E.g., type "BR" → press F3 → inserts "Best Regards".

Tip: AutoCorrect vs AutoText — AutoCorrect fixes mistakes automatically; AutoText inserts pre-saved text blocks on demand.

8. Sample Questions with Answers

Q1. What is the difference between Insert and Overtype mode? 2 Marks▼
Insert Mode: New text is inserted at cursor; existing text shifts right.
Overtype Mode: New text overwrites existing text. Toggled by pressing the Insert key.
Q2. How do you select an entire document using the keyboard? 1 Mark▼
Press Ctrl+A to select all the text in the document.
Q3. What is the Clipboard? What is its use? 2 Marks▼
The Clipboard is a temporary memory storage area. It holds the last cut or copied content so it can be pasted to another location. The content is lost when new content is cut/copied or the computer restarts.
Q4. What is the difference between Cut+Paste and Copy+Paste? 2 Marks▼
Cut+Paste: Moves text from original location to new location (original is removed).
Copy+Paste: Duplicates text — original remains; a copy is placed at new location.
Q5. Write the steps to find and replace a word in LibreOffice Writer. 3 Marks▼
(1) Press Ctrl+H to open Find & Replace. (2) Type the word to find in "Search For". (3) Type the replacement word in "Replace With". (4) Click Replace (one) or Replace All (all). (5) Click Close.
Q6. What do red and blue wavy underlines indicate in Writer? 2 Marks▼
Red wavy underline = Spelling mistake.
Blue wavy underline = Grammar mistake. Right-click to see correction suggestions.
Q7. What is AutoCorrect? Give one example. 2 Marks▼
AutoCorrect automatically fixes common typing mistakes as you type. Example: "teh" is automatically corrected to "the".
