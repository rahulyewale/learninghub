1. Introduction to Word Processing

A Word Processor is application software used to create, edit, format, store and print text documents. It is more powerful than a typewriter because it allows corrections, formatting, and storing of documents.

FeatureTypewriterWord Processor
EditingNot possible once typedEasy — just click and retype
FormattingNo formatting optionsBold, italic, font, size, colour etc.
StoragePaper onlySave as digital file
Spelling checkManual onlyAutomatic spell check
CopiesCarbon paper requiredPrint multiple copies instantly

Popular Word Processors

  • LibreOffice Writer — free and open-source (used in CBSE)
  • Microsoft Word — commercial
  • Google Docs — cloud-based, online

2. Starting LibreOffice Writer

Methods to start LibreOffice Writer:

  1. Start Menu: Click Start → All Programs → LibreOffice → LibreOffice Writer
  2. Desktop Shortcut: Double-click the LibreOffice Writer icon on the desktop
  3. Run Command: Press Windows+R → type swriter → press Enter
  4. Right-click: Right-click on Desktop → New → ODF Text Document
Remember: When Writer opens, a blank document is created automatically, ready for typing.

4. Basic File Operations

Creating a New Document

  • Click File → New → Text Document, OR
  • Press Ctrl+N

Opening an Existing Document

  • Click File → Open, OR
  • Press Ctrl+O → browse to file → click Open

Saving a Document

  1. Click File → Save (or press Ctrl+S)
  2. The Save dialog opens for a new document
  3. Choose the save location (folder)
  4. Type the file name
  5. Choose the file format
  6. Click Save

Save vs Save As

Save (Ctrl+S)Save As (Ctrl+Shift+S)
Saves changes to the same file at the same locationSaves with a new name, location or format
Used to update an existing documentUsed to create a copy of the document

Closing a Document

  • Click File → Close
  • Or click the X on the document tab
  • If unsaved, Writer asks: Save, Discard, or Cancel

7. Sample Questions with Answers

Q1. What is a word processor? Name two examples. 1 Mark▼
A word processor is software used to create, edit, format and print text documents. Examples: LibreOffice Writer, Microsoft Word.
Q2. State any three advantages of a word processor over a typewriter. 2 Marks▼
(1) Editing is easy — text can be corrected without retyping the whole page. (2) Formatting options like bold, italic, font size are available. (3) Documents can be saved digitally and printed multiple times.
Q3. What is the Title Bar? What does it show? 1 Mark▼
The Title Bar is the topmost bar of the Writer window. It shows the name of the current document and the application name (LibreOffice Writer). For an unsaved document, it shows "Untitled1".
Q4. Differentiate between Save and Save As. 2 Marks▼
Save (Ctrl+S): Saves the document at the same location with the same name — used to update.
Save As (Ctrl+Shift+S): Opens dialog to save with a different name, location, or format — used to create a copy.
Q5. Name any five components of the LibreOffice Writer window. 3 Marks▼
Title Bar, Menu Bar, Standard Toolbar, Formatting Toolbar, Ruler, Work Area, Scroll Bars, Status Bar.
Q6. Write keyboard shortcuts for: New, Open, Save, Close, Print. 3 Marks▼
New – Ctrl+N; Open – Ctrl+O; Save – Ctrl+S; Close – Ctrl+W; Print – Ctrl+P.
Q7. What are the different file formats supported by LibreOffice Writer? 3 Marks▼
.odt (ODF – default), .docx (MS Word), .pdf (Portable Document Format), .rtf (Rich Text Format), .txt (Plain Text).
Quick Revision: Word Processor = create, edit, format, save, print documents | Title Bar = document name | Status Bar = page no., word count | Ctrl+N/O/S/P = New/Open/Save/Print | .odt = default format.
