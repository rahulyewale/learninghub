1. What is Mail Merge?

Mail Merge is a feature in LibreOffice Writer that allows you to create a single document template and automatically personalise it for many recipients using data from a list (database or spreadsheet).

Instead of typing separate letters for each person, you write one letter with placeholders, and Mail Merge fills in each person's details automatically.

Example: Your school wants to send invitation letters to 200 parents. With Mail Merge, you write the letter once, and Writer automatically inserts each parent's name, address, and child's name — generating 200 personalised letters in minutes.

2. Uses of Mail Merge

  • Sending personalised invitation or congratulation letters
  • Printing address labels and envelopes for bulk mailing
  • Creating personalised certificates (student's name, grade, class)
  • Sending individualised reports or mark sheets
  • Bulk email campaigns with personalised greetings
  • Printing fee receipts, identity cards, notice letters

4. Steps to Perform Mail Merge in LibreOffice Writer

  1. Open LibreOffice Writer and create or open the Main Document
  2. Go to Tools → Mail Merge Wizard — the wizard guides you step by step
  3. Step 1: Select document type — Letter, E-mail, or Envelope
  4. Step 2: Select starting document (use current document or template)
  5. Step 3: Select the Address List (Data Source)
    • Use an existing list (Calc/Base file)
    • Or create a new list (enter records in a dialog)
  6. Step 4: Create/edit the Salutation (greeting line)
  7. Step 5: Adjust the document layout (margins, address block)
  8. Step 6: Preview the merged documents — check a few records
  9. Step 7: Finalise and merge:
    • Print merged documents directly
    • Or save as a new file containing all merged records
    • Or send as email
Quick Method: Tools → Mail Merge Wizard opens an 8-step interactive wizard that handles all the steps with guidance.

5. Creating a Data Source

The Data Source (address list) is a structured file with rows and columns. Each row is one record (one person). Each column is one field (one piece of information).

CSV File (.csv)Comma-separated values — compatible with many apps
Important: The first row of your data source must contain the field names (headers) like Name, Address, Class. The actual data goes from the second row onwards.

6. Inserting Merge Fields

Merge Fields are placeholders in the main document that get replaced with actual data during the merge. They are shown in double angle brackets: «Name» «City».

How to Insert Merge Fields

  1. Link the data source (done in the wizard)
  2. Place the cursor where you want the field
  3. Go to Insert → Field → More Fields → Database tab, or
  4. Use the Mail Merge Toolbar → Insert Merge Field dropdown
  5. Select the field name (e.g., Name, Address)
  6. Click Insert — the field appears as «Name»

Sample Main Document with Merge Fields

Date: 21 June 2026

Dear «Name»,

We are pleased to inform you that your ward from Class «Class», Roll No. «Roll_No», has been selected for the Annual Prize Distribution Ceremony.

The event will be held at the school auditorium on 30 June 2026.

Yours sincerely,
The Principal

When merged, «Name» is replaced by "Rahul Sharma" for the first record, "Priya Singh" for the second, and so on.

7. Merging and Output Options

Output OptionDescription
Merge to New DocumentCreates a new Writer file with all personalised letters on separate pages. Can be edited before printing.
Merge to PrinterSends all merged letters directly to the printer. Quick but cannot be edited.
Merge to EmailSends personalised emails to each recipient using email client.

Filtering Records

You can choose to merge only specific records:

  • By record number range (e.g., records 1 to 50)
  • By applying a filter (e.g., only students from Class 9A)
Exam Tip: Know the three components: Main Document, Data Source, Merged Document. Know the 3 output options: New Document, Printer, Email.

8. Sample Questions with Answers

Q1. What is Mail Merge? 1 Mark▼
Mail Merge is a feature in LibreOffice Writer that combines a main document (template) with a data source (list) to automatically create personalised documents for multiple recipients.
Q2. Name the three components of Mail Merge and explain each briefly. 3 Marks▼
(1) Main Document: The template containing common text and merge field placeholders. (2) Data Source: A file (spreadsheet/database) with variable data — names, addresses etc. (3) Merged Document: The final personalised output combining the template with each data record.
Q3. What are merge fields? How are they shown in the main document? 2 Marks▼
Merge fields are placeholders in the main document that get replaced by actual data during the mail merge. They are shown within double angle brackets, e.g., «Name», «City».
Q4. State any three uses of Mail Merge. 2 Marks▼
(1) Sending personalised invitation letters to many people. (2) Printing address labels or envelopes. (3) Creating personalised certificates or mark sheets for students.
Q5. What are the three output options when completing a Mail Merge? 3 Marks▼
(1) Merge to New Document: Creates a new file with all merged letters (can be edited). (2) Merge to Printer: Prints all merged letters directly. (3) Merge to Email: Sends personalised emails to each recipient.
Q6. Write the steps to perform Mail Merge using the Wizard in LibreOffice Writer. 5 Marks▼
(1) Open/create the main document in Writer. (2) Tools → Mail Merge Wizard. (3) Select document type (Letter). (4) Select starting document. (5) Select/create address list (data source). (6) Set up salutation/greeting. (7) Arrange address layout. (8) Preview merged records. (9) Finalise: merge to new document, printer or email.
Q7. What should the first row of a data source contain? Why? 2 Marks▼
The first row of the data source must contain the field names (headers) such as Name, Address, Class. These headers are used as merge field names in the main document so Writer knows which column to use for each placeholder.
