📄 Chapter 4 — Getting Started with Word Processor

How to Start LibreOffice Writer

1
Click the Start menu

In Windows, click the Start button (Windows icon) at the bottom-left of the screen.

2
Navigate to LibreOffice

Go to: All Programs → LibreOffice → LibreOffice Writer

Start›All Programs›LibreOffice›LibreOffice Writer
3
Writer opens

A blank document named "Untitled 1" appears, ready for typing.

How to Save a Document for the First Time

1
Press Ctrl+S or go to File → Save

Since this is a new document, the Save As dialog opens automatically.

2
The Save As dialog opens
Save As ✕
Save in:Documents ▾
📁 Class9   📁 Projects   📄 Notes.odt
File Name:
File Type:
3
Type the file name

Click the File Name field and type a meaningful name like "My First Document".

4
Choose file type

Keep it as .odt (default) for LibreOffice, or choose .docx if you need to share with Microsoft Word users.

5
Click Save

The document is saved. The title bar now shows "My First Document – LibreOffice Writer".

Remember: Press Ctrl+S regularly while working to keep saving your changes. You'll never lose work again!

How to Select Text — 3 Methods

1
Method 1: Click and Drag (Mouse)

Click at the START of the text you want to select, hold the mouse button, drag to the END, then release.

📄 document1.odt
The quick brown fox jumps over the lazy dog.

Blue highlight = selected text. Any formatting or edit now applies to this text only.

2
Method 2: Double-click to select one word

Double-click on any word to instantly select the entire word.

Double-click on "brown" → brown is instantly selected
3
Method 3: Keyboard shortcuts
  • Ctrl+A — select entire document
  • Shift+→ — extend selection one character right
  • Shift+End — select to end of line
  • Shift+Ctrl+End — select to end of document

Using Find and Replace

1
Press Ctrl+H

The Find and Replace dialog box opens.

2
The Find and Replace Dialog
Find & Replace ✕
Search For:

3
Type in the Search For field

Type the word you want to find (e.g., "colour").

4
Type in Replace With field

Type the replacement word (e.g., "color").

5
Click Replace All

All instances of "colour" in the document are replaced with "color" in one click. Writer shows a count of replacements made.

Formatting Toolbar

1
Right-click the red-underlined word

A context menu appears with spelling suggestions.

2
Choose the correct spelling

Click the correct word from the list — it replaces the misspelled word instantly.

3
Or press F7 for full spell check

This opens the Spelling dialog that goes through every error one by one with options: Ignore, Change, Add to Dictionary.

The Data Source — How It Should Look

Your data source (e.g., a Calc spreadsheet) must have field names in the first row.

NameClassRoll_NoAddressCity
Rahul Sharma9A1Plot 12, Sec 5Panvel
Priya Singh9B2House 4, MG RoadMumbai
Amit Verma9C3B-9, Shastri NagarThane
Rule: Row 1 = column headings (field names). Row 2 onwards = actual data. The headings become your merge field names: «Name», «Class», «Roll_No» etc.

Step-by-Step: Mail Merge Wizard

1
Open the main document

Open or create your letter template in Writer.

Tools›Mail Merge Wizard…
2
Wizard Step 1 — Select document type

Choose Letter. Click Next.

3
Wizard Step 2 — Select starting document

Choose "Use the current document". Click Next.

4
Wizard Step 3 — Select address list (Data Source)

Click "Select a Different List" and browse to your Calc spreadsheet (.ods file). Click Next.

5
Wizard Steps 4–6 — Set up salutation and layout

Configure the greeting line and address block position if needed. Click Next through each step.

6
Wizard Step 7 — Preview the merged document

Use the arrow buttons to preview each merged letter. Verify that names and data appear correctly.

7
Wizard Step 8 — Finalise and output
📄 New Document
Creates all letters in a new Writer file — editable before printing
🖨️ Printer
Sends directly to printer — quick but not editable
📧 Email
Sends personalised emails to each recipient
