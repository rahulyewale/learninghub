1. Character Formatting

Character Formatting changes the appearance of individual characters or selected text. Access via Format → Character or the Formatting Toolbar.

OptionDescriptionShortcut
Font NameChanges the typeface (e.g., Arial, Times New Roman)—
Font SizeChanges the size of text (measured in points)—
BoldMakes text thick/heavyCtrl+B
ItalicMakes text slant to the rightCtrl+I
UnderlineAdds a line below textCtrl+U
StrikethroughDraws a line through text—
SuperscriptText above baseline (e.g., x²)Ctrl+Shift+P
SubscriptText below baseline (e.g., H₂O)Ctrl+Shift+B
Font ColourChanges colour of text—
HighlightingBackground colour of selected text—
UPPERCASE/lowercaseChange capitalisationFormat → Text → UPPERCASE etc.
Remember: Select the text FIRST, then apply character formatting. Formatting applied without selection affects new text typed at the cursor.

2. Paragraph Formatting

Paragraph Formatting changes the arrangement of an entire paragraph. Access via Format → Paragraph.

Text Alignment

AlignmentDescriptionShortcut
Left AlignText aligned to the left margin (default)Ctrl+L
Centre AlignText centred between marginsCtrl+E
Right AlignText aligned to the right marginCtrl+R
JustifyText spreads evenly to both marginsCtrl+J

Line Spacing

Controls vertical space between lines. Format → Paragraph → Indents and Spacing → Line Spacing.

OptionDescription
Single (1.0)Default spacing — lines close together
1.5 LinesOne and a half times single spacing
Double (2.0)Twice single spacing — large gap between lines
FixedExact height specified in points
ProportionalPercentage of single line height

Indentation

Indentation is the space between the text and the left/right margins.

TypeDescription
Left IndentMoves all lines of paragraph away from left margin
Right IndentMoves all lines of paragraph away from right margin
First Line IndentIndents only the first line of a paragraph (book style)
Hanging IndentAll lines indented EXCEPT the first line (used in bullet lists)

Spacing Before and After Paragraph

Adds extra space before or after a paragraph without pressing Enter multiple times.

3. Page Formatting

Page Formatting controls the overall layout of the page. Access via Format → Page Style.

OptionDescription
Page SizePhysical size of the page. Standard sizes: A4 (210×297 mm), Letter (8.5×11 inch)
OrientationPortrait = tall page (default) | Landscape = wide page
MarginsBlank space around page edges. Default: Top/Bottom/Left/Right = 2.54 cm (1 inch)
HeaderText that appears at the TOP of every page (e.g., title, chapter name)
FooterText that appears at the BOTTOM of every page (e.g., page number, date)
Page NumbersInsert → Header and Footer → Page Number
ColumnsDivides page into newspaper-style columns
Portrait vs Landscape: Portrait is used for letters/reports (tall); Landscape is used for spreadsheets/tables/wide diagrams (wide).

4. Ordered and Unordered Lists

FeatureUnordered List (Bullet)Ordered List (Numbered)
Marker typeBullets (•, ■, ▸)Numbers or letters (1, 2, A, B, i, ii)
Used forItems without specific orderSteps or sequence-based items
ShortcutToolbar bullet buttonToolbar number button
Menu pathFormat → Lists → Unordered ListFormat → Lists → Ordered List

Multilevel Lists

A list within a list (sub-list). Press Tab to go one level deeper, Shift+Tab to go back up.

Tip: To end a list, press Enter twice (once to create empty bullet, once to exit list level).

5. Borders and Shading

Text / Paragraph Borders

Add a decorative or visible border around a paragraph: Format → Paragraph → Borders.

  • Choose box, shadow, or custom border
  • Set border style, width and colour

Page Borders

Format → Page Style → Area/Borders tab — adds a border around the entire page.

Shading / Background Colour

Highlight or background fill for selected text or a paragraph.

Format Painter (Clone Formatting)

Copies formatting from one selection and applies it to another — like a paintbrush for formatting.

  • Select formatted text → click Format Painter (paint bucket icon in toolbar) → click/drag on target text
  • Double-click Format Painter to apply to multiple locations

6. Styles and Templates

Styles

A Style is a saved set of formatting settings (font, size, colour, alignment, etc.) that can be applied to text in one click.

Type of StyleUse
Paragraph StyleApplies formatting to a whole paragraph (Heading 1, Body Text)
Character StyleApplies formatting to selected characters
Page StyleControls page layout (margins, orientation, header/footer)
List StyleDefines look of bullet/numbered lists

Templates

A Template is a pre-formatted document that serves as a starting point. Examples: letter template, resume template, invoice template.

  • File → New → Templates to browse and use templates
  • File → Templates → Save as Template to create your own
Styles speed up work: Instead of formatting each heading manually, apply "Heading 1" style — consistent and quick.

7. Sample Questions with Answers

Q1. What is character formatting? Name any four options. 2 Marks▼
Character formatting changes the appearance of selected text. Options: Font name, Font size, Bold (Ctrl+B), Italic (Ctrl+I), Underline (Ctrl+U), Font colour, Superscript, Subscript.
Q2. Write shortcuts for all four alignment options. 2 Marks▼
Left align – Ctrl+L; Centre – Ctrl+E; Right – Ctrl+R; Justify – Ctrl+J.
Q3. Differentiate between ordered and unordered lists. 2 Marks▼
Unordered list uses bullets (• ■) and is used for items without a specific order.
Ordered list uses numbers or letters (1, 2, A) and is used for step-by-step or sequential items.
Q4. What is the difference between Portrait and Landscape orientation? 2 Marks▼
Portrait: Page is taller than wide (vertical). Default for letters and reports.
Landscape: Page is wider than tall (horizontal). Used for tables, spreadsheets, or wide diagrams.
Q5. What are margins? What is the default margin in Writer? 2 Marks▼
Margins are the blank spaces around the edges of the page — top, bottom, left, and right. The default margin in LibreOffice Writer is 2.54 cm (1 inch) on all sides.
Q6. What is a Style in LibreOffice Writer? Name four types. 3 Marks▼
A Style is a saved set of formatting settings applied in one click. Types: Paragraph Style, Character Style, Page Style, List Style.
Q7. What is Format Painter? How is it used? 2 Marks▼
Format Painter (Clone Formatting) copies the formatting of selected text and applies it to other text. Use: Select formatted text → click the paint-bucket icon → drag over target text.
Quick Revision: Character = text appearance | Paragraph = alignment, spacing, indent | Page = size, margins, orientation | Bold Ctrl+B | Italic Ctrl+I | Align: L/E/R/J | Styles = saved formats | Template = pre-made document.
