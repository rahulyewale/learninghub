1. Print Preview

Print Preview shows exactly how the document will look when printed, before sending it to the printer. This helps avoid wasting paper.

Opening Print Preview

  • File → Print Preview, or
  • Click the Print Preview button in the Standard Toolbar

What you can do in Print Preview

  • View single page, two pages, or all pages at once
  • Zoom in and out to check details
  • Check margins, headers, footers and page layout
  • Click Close Preview to return to editing
Best Practice: Always use Print Preview before printing to check the document layout and avoid printing errors.

2. Page Setup Before Printing

Before printing, set up the page correctly using Format → Page Style.

SettingDescription
Page SizeA4 is standard for most documents. Match with actual paper loaded in printer.
OrientationPortrait (vertical) or Landscape (horizontal)
MarginsSet top, bottom, left, right margins as required
Header / FooterSet up text that appears at top/bottom of every page
Page NumbersInsert page numbers in header or footer
Paper SourceSelect which paper tray to use (if printer has multiple trays)

3. The Print Dialog Box

Open the Print dialog: File → Print or press Ctrl+P.

Sections of the Print Dialog

SectionOptionDescription
PrinterNameSelect the connected printer from the dropdown
PropertiesAccess printer-specific settings (quality, paper type)
Print to FileSave print output as a file instead of printing physically
Print RangeAll PagesPrint the entire document
Current PagePrint only the page currently visible
PagesEnter specific page numbers, e.g., 1-3, 5, 8 (prints pages 1,2,3,5,8)
SelectionPrint only the currently selected text
CopiesNumber of CopiesHow many copies to print
CollateIf checked, prints complete sets (1,2,3 then 1,2,3); unchecked prints all copies of page 1, then page 2...

4. Additional Print Options

Duplex / Two-sided Printing

Printing on both sides of the paper. Requires a printer that supports duplex printing.

  • Long-edge binding: flip on long side (like a book)
  • Short-edge binding: flip on short side (like a notepad)

Print Brochure

Prints two pages side-by-side on one sheet, folded to create a booklet (brochure format).

Print in Black and White

Converts coloured document to grayscale for printing on a B&W printer to save colour ink.

Number of Pages per Sheet

Print multiple document pages on one sheet of paper. E.g., 2 pages per sheet, 4 pages per sheet.

Page Order

OrderDescription
Left to RightPages appear in normal reading order
Right to LeftUsed for right-to-left languages
ReversedPrints last page first — useful for printers that stack face-up
Tip: Click the More Options or Print Options button in the Print dialog to access advanced settings like paper source, print quality, and printer properties.

5. Exporting to PDF

PDF (Portable Document Format) creates a read-only version of the document that looks the same on any device or printer.

Why use PDF?

  • Maintains exact formatting on all devices
  • Cannot be easily edited (read-only)
  • Smaller file size than .odt in many cases
  • Universally accepted for sharing official documents

Export to PDF in LibreOffice Writer

  1. File → Export as PDF
  2. The PDF Options dialog opens
  3. Set page range, image quality, security (password) etc.
  4. Click Export
  5. Choose save location and filename → click Save
Quick Export: File → Export Directly as PDF exports immediately with default settings.

6. Sample Questions with Answers

Q1. What is Print Preview? Why is it used? 2 Marks▼
Print Preview shows exactly how the document will appear when printed. It is used to check layout, margins, headers/footers and avoid printing mistakes before sending to the printer.
Q2. How do you open the Print dialog? What is its shortcut? 1 Mark▼
File → Print, or press Ctrl+P to open the Print dialog box.
Q3. What are the different print range options available in the Print dialog? 3 Marks▼
(1) All Pages – prints entire document. (2) Current Page – prints only the page visible on screen. (3) Pages – prints specific page numbers entered (e.g., 2-4, 7). (4) Selection – prints only selected text.
Q4. What does the Collate option do while printing? 2 Marks▼
Collate organises multiple copies into complete sets. With Collate ON: prints 1,2,3 then 1,2,3 again. With Collate OFF: prints all copies of page 1, then all of page 2, etc.
Q5. What is PDF? Write two advantages of saving a document as PDF. 2 Marks▼
PDF (Portable Document Format) is a read-only file format. Advantages: (1) Maintains exact formatting on any device/printer. (2) Cannot be easily modified — suitable for official documents.
Q6. Write the steps to export a document as PDF in LibreOffice Writer. 3 Marks▼
(1) Click File → Export as PDF. (2) The PDF Options dialog opens. (3) Set page range and quality. (4) Click Export. (5) Choose save location and file name → click Save.
Q7. What is duplex printing? 1 Mark▼
Duplex printing means printing on both sides of a sheet of paper. It requires a printer that supports double-sided (duplex) printing.
Quick Revision: Ctrl+P = Print | Print Preview = check before printing | Range = All/Current/Pages/Selection | Collate = full sets | PDF = read-only, fixed format | Duplex = both sides | Export as PDF = File → Export as PDF.
