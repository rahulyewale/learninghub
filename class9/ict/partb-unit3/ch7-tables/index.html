1. Introduction to Tables

A Table organises data into rows and columns. Tables are used to compare data, create structured layouts, and display information neatly.

Parts of a Table

TermDescription
RowHorizontal arrangement of cells. Rows run left to right.
ColumnVertical arrangement of cells. Columns run top to bottom.
CellThe intersection (box) of a row and column where data is entered.
Cell AddressPosition of a cell identified by row and column (e.g., Row 2, Col 3).
Column HeaderThe first row used as headings/labels for each column.
Table BorderLines around and within the table cells.

2. Creating a Table

Method 1: Insert Table Dialog

  1. Click where you want the table
  2. Go to Table → Insert Table (or Ctrl+F12)
  3. In the dialog box, set number of Columns and Rows
  4. Check "Heading" if you want the first row as header
  5. Click OK

Method 2: Table Grid (Toolbar)

  1. Click Insert → Table
  2. Drag over the grid to select number of rows and columns
  3. Release the mouse — table is inserted

Method 3: Convert Text to Table

Select tabbed or separated text → Table → Convert → Text to Table → choose separator.

Tip: Start with the minimum rows and columns needed — you can always add more later.

New Row: Press Tab in the last cell of the last row to automatically add a new row at the bottom.

4. Inserting and Deleting Rows and Columns

Inserting Rows

  • Click in a row → Table → Insert Rows Above / Insert Rows Below
  • Or right-click in row → Insert → Rows Above/Below

Inserting Columns

  • Click in a column → Table → Insert Columns Before / Insert Columns After
  • Or right-click → Insert → Columns Before/After

Deleting Rows / Columns

  • Click in row/column → Table → Delete → Rows or Columns
  • Or right-click → Delete → Rows/Columns

Selecting Table Elements

Adjusting Row Height and Column Width

  • Drag the border/line between rows or columns
  • Or: Table → Table Properties → Columns / Rows tabs
  • AutoFit: Table → Size → Optimal Width / Optimal Height

5. Merging and Splitting Cells

Merge Cells

Merging combines two or more adjacent cells into one larger cell.

  1. Select the cells to merge
  2. Table → Merge Cells (or right-click → Merge Cells)

Use: Merging is useful for table headings that span multiple columns, like a title row.

Split Cells

Splitting divides one cell into multiple rows or columns.

  1. Click in the cell to split
  2. Table → Split Cells
  3. Enter number of rows and/or columns to split into
  4. Click OK

Split Table

Divides a table into two separate tables at the selected row: Table → Split Table.

Merge vs Split: Merge = many cells → one big cell | Split = one cell → multiple cells.

6. Formatting a Table

Table Borders

  • Select cells → Format → Table → Borders tab
  • Choose border style, colour and width
  • Apply to specific sides or all sides

Shading / Background

  • Select cells → Format → Table → Background tab
  • Choose colour to fill cell backgrounds (useful for header rows)

Text Alignment in Cells

Format → Table → Table tab, or use toolbar alignment buttons. Vertical alignment: Top, Centre, Bottom.

AutoFormat

Apply pre-designed table formatting in one click: Table → AutoFormat Styles → choose a style → OK.

Table Properties

Table → Table Properties opens a dialog to control: table width, alignment on page, column widths, borders, background.

7. Sorting Data in a Table

Sorting arranges the rows of a table in a particular order based on the content of a column.

  1. Click inside the table
  2. Go to Table → Sort
  3. Choose the sort key (which column), sort type (text/number), and order (ascending/descending)
  4. Click OK
Sort OrderDescription
AscendingA to Z / smallest to largest / oldest to newest
DescendingZ to A / largest to smallest / newest to oldest

8. Sample Questions with Answers

Q1. What is a table? Name its three basic parts. 2 Marks▼
A table is a structure of rows and columns used to organise and display data. Three basic parts: Row (horizontal), Column (vertical), Cell (intersection of row and column).
Q2. Write the steps to insert a table using the Insert Table dialog. 3 Marks▼
(1) Click where you want the table. (2) Go to Table → Insert Table. (3) Set number of rows and columns. (4) Choose heading option if needed. (5) Click OK.
Q3. What key is used to move to the next cell in a table? 1 Mark▼
Press Tab to move to the next cell. Press Shift+Tab to move to the previous cell.
Q4. What happens when Tab is pressed in the last cell of a table? 1 Mark▼
A new row is automatically added at the bottom of the table.
Q5. What is the difference between merging and splitting cells? 2 Marks▼
Merging: Combines two or more adjacent cells into one large cell. Used for spanning headers.
Splitting: Divides one cell into multiple rows or columns. Access: Table → Merge Cells / Split Cells.
Q6. How can you sort data in a Writer table? 3 Marks▼
(1) Click inside the table. (2) Go to Table → Sort. (3) Choose the sort key (column), sort type, and order (ascending or descending). (4) Click OK. Ascending = A to Z; Descending = Z to A.
Q7. How do you add borders and background to table cells? 2 Marks▼
Select cells → Format → Table → Borders tab (choose style, colour, width for borders) → Background tab (choose fill colour). Or use AutoFormat for a pre-designed table style.
Quick Revision: Row = horizontal | Column = vertical | Cell = intersection | Tab = next cell | Ctrl+F12 = insert table | Merge = combine cells | Split = divide cell | Table → Sort = arrange rows | AutoFormat = pre-designed styles.
