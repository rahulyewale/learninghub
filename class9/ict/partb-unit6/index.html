2. World Wide Web (WWW) and URLs

The World Wide Web (WWW) is a collection of websites and web pages accessible through the internet. It was invented by Tim Berners-Lee in 1989.

A URL (Uniform Resource Locator) is the address of a specific web page or resource.

Parts of a URL

Example: https://www.ncert.nic.in/textbook.php

PartExampleMeaning
Protocolhttps://How data is transferred (HTTP = web, HTTPS = secure)
SubdomainwwwWorld Wide Web prefix
Domain Namencert.nic.inRegistered name of the website
Domain Extension (TLD).in / .com / .orgCountry or organisation type
Path/textbook.phpSpecific page or file on the server

6. Cyber Safety and Security

Cyber Safety means protecting yourself and your information from threats on the internet.

Common Cyber Threats

ThreatMeaning
VirusMalicious program that attaches to files and spreads
MalwareAny malicious software (virus, worm, trojan, ransomware)
PhishingFake emails/websites that trick users into sharing passwords
HackingUnauthorised access to computer systems or data
Identity TheftStealing someone's personal information for misuse
CyberbullyingUsing technology to harass or intimidate someone
SpamUnsolicited bulk emails/messages
⚠ Warning: Never share your passwords, OTPs, Aadhaar, bank details, or personal photos with strangers or on unsafe websites.

Cyber Safety Practices

  • Use strong passwords (mix of uppercase, lowercase, numbers, symbols)
  • Change passwords regularly; never reuse passwords
  • Enable two-factor authentication (2FA)
  • Do not click unknown links or open suspicious attachments
  • Use licensed antivirus software and keep it updated
  • Use HTTPS websites for sensitive transactions
  • Log out from accounts after use on shared computers
  • Keep operating system and software up to date
  • Avoid using public Wi-Fi for banking or personal data
  • Report cyberbullying or abuse to parents/teachers/authorities

Strong Password Guidelines

  • At least 8–12 characters long
  • Mix of letters (upper and lower case), numbers, and symbols
  • Avoid using names, birthdays, or common words
  • Use a password manager to manage multiple passwords
Memory tip: Cyber safety = strong passwords + updated software + no sharing of personal data + HTTPS only.

7. Sample Questions with Answers

Q1. What is an IP Address? 1 Mark▼
Answer: An IP Address (Internet Protocol Address) is a unique numerical identifier assigned to each device on a network, used to send and receive data.
Q2. Expand URL and write its parts with an example. 2 Marks▼
Answer: URL = Uniform Resource Locator. Example: https://www.example.com/page. Parts: Protocol (https://), subdomain (www), domain (example.com), path (/page).
Q3. Differentiate between CC and BCC in email. 2 Marks▼
Answer: CC (Carbon Copy) sends a copy to additional recipients and their addresses are visible to everyone. BCC (Blind Carbon Copy) sends a hidden copy — the BCC recipient's address is not shown to others.
Q4. What is phishing? How can you protect yourself? 3 Marks▼
Answer: Phishing is when hackers send fake emails or create fake websites to trick users into sharing passwords, OTPs, or personal information. Protection: Do not click unknown links, verify sender addresses, use 2FA, and check for HTTPS.
Q5. What is the difference between HTTP and HTTPS? 2 Marks▼
Answer: HTTP (HyperText Transfer Protocol) transfers data without encryption. HTTPS (HTTP Secure) encrypts data using SSL/TLS, making it safe for sensitive transactions like banking and shopping.
Q6. List any five cyber safety practices. 5 Marks▼
Answer: (1) Use strong and unique passwords. (2) Enable two-factor authentication. (3) Do not click suspicious links or attachments. (4) Use updated antivirus software. (5) Avoid sharing personal data on social media or emails.
Q7. Name five popular web browsers and four search engines. 3 Marks▼
Answer: Browsers: Chrome, Firefox, Edge, Safari, Opera. Search engines: Google, Bing, Yahoo, DuckDuckGo.
Q8. What is cyberbullying? What should you do if you experience it? 3 Marks▼
Answer: Cyberbullying is using digital technology to harass, threaten, embarrass, or target someone. If you experience it, do not respond to the bully, block them, save evidence (screenshots), and report it to parents, teachers, or authorities.
Quick revision: Internet = global network; WWW invented by Tim Berners-Lee; URL = address of a page; Browser navigates websites; Email fields: To/CC/BCC/Subject/Body; HTTPS = secure; Threats: virus, phishing, hacking, cyberbullying; Stay safe with strong passwords and no sharing of personal data.
