1. Introduction

Data Entry is the process of entering, updating, and managing data in a computer system. Good keyboarding skills improve speed and accuracy, which are essential for IT-ITeS jobs.

TermMeaning
Data EntryInputting data into a computer system
KeyboardingUsing the keyboard to type accurately and quickly
WPMWords Per Minute – typing speed measurement
AccuracyPercentage of correct characters typed
Industry standard: A data entry professional should aim for at least 35–40 WPM with 95%+ accuracy.

2. Keyboard Layout (QWERTY)

The standard keyboard layout is called QWERTY (named after the first six letters in the top letter row).

Home Row: Fingers should always return to A S D F (left hand) and J K L ; (right hand) when not typing. This is the foundation of touch typing.

3. Touch Typing

Touch Typing means typing without looking at the keyboard. Each finger is assigned specific keys.

Finger assignment (Home Row basis)

Left Hand FingerKeys Covered
Pinky (little finger)Q, A, Z and left edge keys
Ring fingerW, S, X
Middle fingerE, D, C
Index fingerR, T, F, G, V, B
ThumbSpace bar
Right Hand FingerKeys Covered
Index fingerY, U, H, J, N, M
Middle fingerI, K, ,
Ring fingerO, L, .
Pinky (little finger)P, ;, /, and right edge keys
ThumbSpace bar

Benefits of Touch Typing

  • Higher speed and productivity
  • Reduces errors
  • Less strain on eyes and neck
  • Preferred skill in IT-ITeS jobs

4. Data Entry Skills

Types of Data Entry

TypeDescriptionExample
Manual Data EntryTyping data into forms/tablesEmployee information form
Numeric Data EntryEntering numbers using numeric keypadFinancial records
Online Data EntryEntering data in web-based systemsOnline order processing
Offline Data EntryEntering data in local applicationsSpreadsheet data entry

Good Data Entry Practices

  • Check source data before typing
  • Use Tab key to move between fields
  • Verify data after entry (proofreading)
  • Use AutoFill and AutoCorrect features when available
  • Save work frequently (Ctrl+S)

Ergonomics at the Workstation

  • Screen at eye level
  • Feet flat on the floor
  • Wrists straight, not bent while typing
  • Take breaks every 30–45 minutes
  • Adequate lighting to reduce eye strain

6. Sample Questions with Answers

Q1. What is touch typing? 1 Mark▼
Answer: Touch typing is the technique of typing on a keyboard without looking at the keys, using muscle memory. Each finger is assigned specific keys.
Q2. What is the Home Row? Name the keys it contains. 2 Marks▼
Answer: The Home Row is the middle row of the keyboard where fingers rest when not typing. It contains: A S D F G H J K L ; for the left and right hands.
Q3. What does WPM stand for? Why is it important? 2 Marks▼
Answer: WPM stands for Words Per Minute. It measures typing speed. Higher WPM with accuracy is required for data entry and IT-ITeS jobs to improve productivity.
Q4. State any three good data entry practices. 3 Marks▼
Answer: (1) Verify source data before entering. (2) Proofread data after entry. (3) Save work frequently using Ctrl+S.
Q5. Write keyboard shortcuts for: Copy, Paste, Undo, Save, Select All. 3 Marks▼
Answer: Copy – Ctrl+C; Paste – Ctrl+V; Undo – Ctrl+Z; Save – Ctrl+S; Select All – Ctrl+A.
Q6. Write any four ergonomic rules to follow while working at a computer workstation. 4 Marks▼
Answer: (1) Keep screen at eye level. (2) Keep feet flat on floor. (3) Wrists should be straight while typing. (4) Take regular breaks to reduce eye and muscle strain.
Q7. Describe the four rows of a standard keyboard. 4 Marks▼
Answer: (1) Number Row – contains digits 1–0 at the top. (2) QWERTY Row (Top) – Q to P. (3) Home Row – A to ; (middle row where fingers rest). (4) Bottom Row – Z to / .
Quick revision: QWERTY keyboard; Home Row = A S D F G H J K L ; ; Touch Typing = no looking at keys; WPM = typing speed; Ctrl+C copy, Ctrl+V paste, Ctrl+Z undo.
