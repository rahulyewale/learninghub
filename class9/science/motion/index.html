1. What is Motion?

Motion is the change in position of an object with time.

An object is said to be in motion if its position changes relative to a reference point.

Reference point matters: A passenger sitting in a moving bus is at rest with respect to the bus, but in motion with respect to the road.

Types of Motion

2. Distance, Displacement and Speed

Distance

Distance is the total path length covered by an object.

Displacement

Displacement is the shortest distance from initial to final position in a specified direction.

DistanceDisplacement
Scalar quantityVector quantity
Always positiveCan be positive, negative or zero
Depends on pathDepends only on initial and final positions

Speed

Speed is the distance covered per unit time.

Speed = Distance / Time

SI unit: m/s

Other common unit: km/h

Average Speed

Average Speed = Total Distance / Total Time

Tip: If a body covers different distances in different time intervals, use average speed.

3. Velocity and Acceleration

Velocity

Velocity is the displacement per unit time in a given direction.

Velocity = Displacement / Time

Velocity is a vector quantity, so direction is important.

Acceleration

Acceleration is the rate of change of velocity.

Acceleration = (Final velocity - Initial velocity) / Time

SI unit: m/s²

Uniform Acceleration

When velocity changes by equal amounts in equal intervals of time, the motion has uniform acceleration.

Retardation / Deceleration

When velocity decreases with time, acceleration is negative. This is called retardation or deceleration.

Exam point: If an object is moving with constant velocity, acceleration is zero.

5. Equations of Motion (Till This Topic)

For uniformly accelerated motion, the three equations are:

v = u + at
s = ut + 1/2 at²
v² = u² + 2as

Where:

  • u = initial velocity
  • v = final velocity
  • a = acceleration
  • t = time
  • s = displacement

How to remember them

  • 1st equation: velocity after time
  • 2nd equation: displacement from time
  • 3rd equation: relation without time
Important: Use consistent units. If speed is in km/h, convert to m/s for calculations in SI units.

7. Sample Questions with Answers

Q1. Define motion. 1 Mark
Answer: Motion is the change in position of an object with time.
Q2. What is the difference between distance and displacement? 2 Marks
Answer: Distance is the total path length covered, while displacement is the shortest straight-line distance from initial to final position in a given direction.
Q3. Write the formula for speed and mention its SI unit. 1 Mark
Answer: Speed = Distance / Time. SI unit is m/s.
Q4. Why is velocity a vector quantity? 2 Marks
Answer: Velocity has both magnitude and direction. Since direction is included, it is a vector quantity.
Q5. What is acceleration? 2 Marks
Answer: Acceleration is the rate of change of velocity with time. Its SI unit is m/s².
Q6. State any two features of a distance-time graph for uniform motion. 2 Marks
Answer: For uniform motion, the distance-time graph is a straight line and its slope gives speed.
Q7. Write the three equations of motion. 3 Marks
Answer: v = u + at; s = ut + 1/2 at²; v² = u² + 2as.
Q8. A body starts from rest and attains a velocity of 20 m/s in 5 s. Find acceleration. 3 Marks
Answer: u = 0, v = 20 m/s, t = 5 s. Using a = (v-u)/t = (20-0)/5 = 4 m/s².
Q9. What does the slope of a velocity-time graph represent? 1 Mark
Answer: The slope of a velocity-time graph represents acceleration.
Q10. State one difference between uniform and non-uniform motion. 2 Marks
Answer: In uniform motion, equal distances are covered in equal intervals of time. In non-uniform motion, unequal distances are covered in equal intervals of time.

8. Remember These Points

  • Distance is always greater than or equal to displacement.
  • Speed is scalar; velocity is vector.
  • Acceleration can be negative when speed decreases.
  • Uniform motion means constant speed in a straight line.
  • Use SI units in formulas.
  • v = u + at is the most basic motion equation.
