Numbers are classified into different sets based on their properties. The number system used in Class 9 is mainly the set of real numbers.

2. Irrational Numbers

An irrational number cannot be expressed in the form p/q, where p and q are integers and q ≠ 0.

Examples

  • √2, √3, √5
  • π
  • Non-terminating, non-repeating decimals

How to prove a number is irrational?

Usually by contradiction. For example, √2 is irrational because if it were rational, it would lead to a contradiction in parity (even/odd) arguments.

Exam point: A decimal expansion that neither terminates nor repeats is irrational.

3. Real Numbers and Their Properties

Real numbers are all numbers that can be represented on the number line.

Properties

Euclid’s Division Lemma

For any two positive integers a and b, there exist unique integers q and r such that:

a = bq + r, where 0 ≤ r < b

Use: This lemma is a base for finding HCF and proving number properties.

4. Decimal Expansion of Rational Numbers

Type of decimalExampleNature
Terminating0.25, 1.75Rational
Repeating0.333..., 0.142857...Rational
Non-terminating, non-repeating√2, πIrrational

Key rule

A rational number p/q has a terminating decimal expansion if, after simplification, the denominator contains only factors 2 and/or 5.

If q = 2^m × 5^n, then decimal expansion terminates.

5. Sample Questions with Answers

Q1. Define a rational number. 1 Mark
Answer: A rational number is any number that can be written in the form p/q, where p and q are integers and q ≠ 0.
Q2. Is √2 rational or irrational? Give reason. 2 Marks
Answer: √2 is irrational because it cannot be expressed as p/q and its decimal expansion is non-terminating and non-repeating.
Q3. State Euclid’s division lemma. 2 Marks
Answer: For any positive integers a and b, there exist unique integers q and r such that a = bq + r, where 0 ≤ r < b.
Q4. When does a rational number have a terminating decimal expansion? 2 Marks
Answer: When the denominator in simplest form is of the form 2^m × 5^n.
Q5. Differentiate between rational and irrational numbers. 3 Marks
Answer: Rational numbers can be expressed as p/q and have terminating or repeating decimals; irrational numbers cannot be expressed as p/q and have non-terminating, non-repeating decimals.

6. Quick Revision Tips

  • Check if numbers can be written as p/q
  • Terminating or repeating decimal = rational
  • Non-terminating non-repeating = irrational
  • Use Euclid’s lemma for HCF and proofs
  • Remember the hierarchy of number sets
